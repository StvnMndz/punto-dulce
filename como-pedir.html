Inicio / Cómo pedir

Dos formas de pedir

Elige lo que mejor se acomode a tu ocasión: algo directo para hoy, o una torta pensada para una fecha especial.

🛵 Pedido por delivery

  1. Elige tus productos de venta directa del catálogo.
  2. Indica tu dirección de entrega.
  3. Selecciona tu método de pago.
  4. Confirmamos y coordinamos la entrega.
Ideal para hoy mismo

🎂 Pedido por encargo

  1. Personaliza tu torta: tamaño, sabor, relleno y decoración.
  2. Elige la fecha de entrega deseada.
  3. Registra el anticipo para confirmar la producción.
  4. Seguimos el proceso hasta el día de entrega.
Ideal para cumpleaños y eventos

¿Quién hace qué?

Así se organiza el trabajo entre el cliente y el personal de la pastelería en cada pedido.

👤 El cliente puede

  • Consultar el catálogo y ver precios y características.
  • Personalizar productos por encargo.
  • Realizar pedidos y solicitar delivery.
  • Elegir fecha de entrega para pedidos por encargo.
  • Seleccionar método de pago y registrar el anticipo.
  • Consultar el estado de su pedido.

🧑‍🍳 El personal puede

  • Administrar el catálogo, productos y precios.
  • Revisar las personalizaciones solicitadas.
  • Recibir y confirmar pedidos.
  • Verificar anticipos.
  • Organizar pedidos según fecha de entrega.
  • Actualizar el estado de los pedidos.
